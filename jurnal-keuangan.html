Sambungkan ke server

Tempel alamat Web App dan kunci rahasia yang sama di setiap perangkat (laptop & HP) agar datanya tersinkron. Lihat tutorial di bawah tombol ini kalau belum membuatnya.

Belum punya alamat server? Lihat cara buatnya (gratis, 5 menit)
  1. Buka sheets.google.com → buat spreadsheet baru, beri nama bebas.
  2. Menu Extensions/Ekstensi → Apps Script.
  3. Hapus semua kode bawaan, ganti dengan kode dari tombol "Salin kode server" di bawah.
  4. Klik ikon ⚙️ Project Settings di sidebar kiri → Script Properties → Add property: name SECRET_KEY, value bebas (ingat-ingat, ini kunci rahasia Anda).
  5. Klik Deploy → New deployment → pilih tipe Web app → Execute as: Me, Who has access: Anyone → Deploy. Izinkan akses saat diminta (klik Advanced → Go to project → Allow).
  6. Salin Web app URL yang muncul, tempel di kolom "Alamat Web App" di atas. Isi kolom "Kunci rahasia" persis sama dengan value SECRET_KEY tadi.
